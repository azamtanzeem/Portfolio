# European Football Analytics: 23/24 Season

Exploratory analysis and ML modelling on 2,852 players across Europe's top 5 leagues.

## Key outputs
- Finishing difference metric identifying clinical outliers (Sørloth +10.7, Guirassy +7.2)
- Elite scorer classifier handling class imbalance — Random Forest at 53% precision on minority class
- Custom Playmaker Index combining xAG/90, progressive passes, and progressive carries
- Player archetype segmentation: Architect / Ball-Carrier / Total Package

## Stack
Python · Pandas · Scikit-learn · Seaborn · Scipy
