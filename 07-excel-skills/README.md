# Excel Skills Practice

**Date:** 27 June 2025
**Purpose:** Interview-ready Excel demonstration covering 7 core skills

## Skills Covered

| Skill | Description |
|---|---|
| VLOOKUP | Basic column lookup with exact match |
| INDEX-MATCH | Flexible two-way lookup — does not break on column inserts |
| SUMIF / SUMIFS | Conditional aggregation by one and two criteria |
| COUNTIFS | Count rows matching multiple conditions simultaneously |
| Nested IF / IFS | Multi-tier classification logic (Performance Tier, Bonus) |
| Pivot Tables | Multi-value summary with slicer and pivot chart |
| Conditional Formatting | Color scales, top-N highlights, row-level formula-based rules |
| Data Validation | Dropdown lists with error alerts linked to live SUMIFS lookup |

## Dataset
- 20 employees across 4 departments (Sales, HR, Finance, Tech) and 2 regions (UAE, KSA)
- Fields: Employee, Department, Salary, Sales, Region, Hire_Date, Performance Tier, Tier_IFS, Bonus
